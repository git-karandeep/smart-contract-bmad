Story 0.13 — Establish Security Baseline

As a platform architect,
I want baseline security controls established before implementing business functionality,
so that security is built into the platform rather than added later.

Scope
Secrets management
API authentication foundation
Input validation
TLS configuration
Dependency scanning
Container scanning
Smart-contract security checks
Acceptance Criteria
No secrets in Git
Dependency vulnerabilities are scanned
Input validation framework configured
Security configuration documented
Security assumptions documented
