Story 0.1 — Initialize Git Repository

As a developer,
I want a properly structured Git repository,
so that the project can be developed collaboratively with consistent source control practices.

Acceptance Criteria
Repository is initialized
.gitignore is configured
README.md exists
LICENSE is defined where applicable
Branching strategy is documented
Initial project directory structure is created
No secrets or credentials are committed

Technical Tasks
Create repository
↓
Create README
↓
Create .gitignore
↓
Create project directories
↓
Initial commit
