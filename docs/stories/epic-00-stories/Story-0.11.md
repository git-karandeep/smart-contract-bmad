Story 0.11 — Configure Docker Compose

As a developer,
I want the complete development infrastructure available through Docker Compose,
so that a new developer can start the platform consistently.

Infrastructure
Docker Compose
│
├── Spring Boot
├── mongoDB
├── Kafka
├── Kafka UI
└── Local Blockchain
Command
docker compose up
Acceptance Criteria

A clean machine can start the development environment with documented commands.
