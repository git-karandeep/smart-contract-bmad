# Actors and Success Criteria

## Actors

- Issuer
- Investor
- Compliance officer
- Administrator
- Settlement service

## Success criteria

- Successful token creation is possible for authorized issuers.
- Compliance validation occurs before transfer execution.
- Blockchain transaction confirmation is tracked and enforced.
- Automatic reconciliation handles drift or failed events.
- Operators can trace a transfer from request to chain settlement.

## Definition of done

The platform is considered successful when each transfer can be accepted, validated, processed, confirmed, and reconciled without data loss or duplicate settlement execution.
